No Puppeteer — open a window & try to touch its DOM

This page is normal browser JavaScript only (no Node, no Puppeteer). Serve it over http://localhost (see terminal instructions), then use the buttons.

  • Popup blocker: yes — window.open usually needs a user gesture (button click). A timer alone often gets blocked.
  • DOM access: blocked by the Same-Origin Policy, not CORS. CORS is about HTTP responses to fetch/XHR. Cross-window otherWindow.document is a different rule.
